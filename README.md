# ShopKart Data Analysis Dashboard
## Project Objective
The ShopKart store wants to create an annual sales report. So that, the Owner of the ShopKart store can understand their customer and grow more sales.
## Dataset used
- <a href="https://github.com/RAJNISH2005/Data-Analysis-Dashboard/blob/main/ShopKart%20Data%20Analysis.xlsx">Dataset</a>

## Question (KPIs)
- What is the total sales revenue?
- What is the total number of orders?
- Which month generated the highest sales?
- Which month had the highest number of orders?
- What is the sales contribution by gender?
- Which sales channel generated the highest revenue?
- Which state has the highest sales?
- What is the overall order delivery rate?
- What percentage of orders were cancelled, returned, or refunded?
- Which age group contributes the most orders?

## Process
- Verify data for any missing values and anomalies, and sort out the same.
- Made sure data is consistent and clean with respect to data type, data format and value used.
- Created pivot tables according to the questions asked.
- Merge all pivot tables into once dashboard and apply slicer to make dynamic.
